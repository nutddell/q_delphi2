# niti-mng

Web App แบบประเมินความสอดคล้อง (IOC) — การพัฒนารูปแบบศักยภาพของผู้จัดการนิติบุคคลในการบริหารระบบการดูแลอาคารที่พักอาศัยในยุคเศรษฐกิจดิจิทัล
(ส่วนที่ 1 = 5 ข้อ, ส่วนที่ 2 = 5 องค์ประกอบ 75 ข้อ, ส่วนที่ 3 = ข้อเสนอแนะปลายเปิด) ข้อคำถามตรงตามต้นฉบับทุกข้อ

## ไฟล์
- `code.gs` — ฝั่ง Google Apps Script (ข้อคำถาม, login, ตรวจการตอบซ้ำ, บันทึกลง Google Sheet, สรุป IOC)
- `index.html` — หน้าเว็บ (โทนสีเหลือง)

## วิธีติดตั้ง
1. สร้าง Google Sheet ใหม่ → เมนู **ส่วนขยาย > Apps Script**
2. วางเนื้อหา `code.gs` ลงในไฟล์ `Code.gs` (หรือเปลี่ยนชื่อเป็น `code.gs`)
3. กด **+ > HTML** ตั้งชื่อ `index` แล้ววางเนื้อหา `index.html`
4. **ทำให้ใช้งานได้ (Deploy) > การทำให้ใช้งานได้รายการใหม่ > เว็บแอป**
   - เรียกใช้ในฐานะ: **ฉัน**
   - ผู้ที่มีสิทธิ์เข้าถึง: **ทุกคน**
5. ส่ง URL ของเว็บแอปให้ผู้เชี่ยวชาญ

## ผู้ใช้
- ชื่อผู้ใช้ `niti01` – `niti21` (21 คน) รหัสผ่านเริ่มต้น = ชื่อผู้ใช้ (เช่น niti05 / niti05)
- แก้รหัสผ่านได้ในตัวแปร `USERS` ใน `code.gs`
- แต่ละผู้ใช้ส่งได้ **1 ครั้ง** ถ้าส่งแล้วจะเข้าทำซ้ำไม่ได้ (ตรวจทั้งตอน login และตอนส่ง ใช้ LockService กันการส่งพร้อมกัน)

## ผลลัพธ์ใน Google Sheet
- ชีต `responses` — คำตอบรายคน (IOC −1/0/+1 และข้อเสนอแนะรายข้อ)
- ชีต `ioc_summary` — ค่า IOC รายข้อ (ผ่านเกณฑ์เมื่อ ≥ 0.50) อัปเดตอัตโนมัติทุกครั้งที่มีผู้ส่ง หรือรัน `updateSummary` เอง
