# niti-mng

Web App แบบประเมินความสอดคล้อง (IOC) — การพัฒนารูปแบบศักยภาพของผู้จัดการนิติบุคคลในการบริหารระบบการดูแลอาคารที่พักอาศัยในยุคเศรษฐกิจดิจิทัล
(ส่วนที่ 1 = 5 ข้อ, ส่วนที่ 2 = 5 องค์ประกอบ 75 ข้อ, ส่วนที่ 3 = ข้อเสนอแนะปลายเปิด) ข้อคำถามตรงตามต้นฉบับทุกข้อ

## ไฟล์
- `code.gs` — ฝั่ง Google Apps Script (ข้อคำถาม, login, ตรวจการตอบซ้ำ, บันทึกลง Google Sheet, สรุป IOC)
- `index.html` — หน้าเว็บ (โทนสีเหลือง)

## วิธีติดตั้ง
1. สร้าง Google Sheet ใหม่ → เมนู **ส่วนขยาย > Apps Script**
2. วางเนื้อหา `code.gs` ลงในไฟล์ `Code.gs` (หรือเปลี่ยนชื่อเป็น `code.gs`)
3. กด **+ > HTML** ตั้งชื่อ `index` แล้ววางเนื้อหา `index.html`
4. **ทำให้ใช้งานได้ (Deploy) > การทำให้ใช้งานได้รายการใหม่ > เว็บแอป**
   - เรียกใช้ในฐานะ: **ฉัน**
   - ผู้ที่มีสิทธิ์เข้าถึง: **ทุกคน**
5. ส่ง URL ของเว็บแอปให้ผู้เชี่ยวชาญ

## ผู้ใช้
- ชื่อผู้ใช้ `ioc1` – `ioc5` (ผู้เชี่ยวชาญ 5 ท่าน) **ไม่ใช้รหัสผ่าน** แก้รายชื่อได้ในตัวแปร `USERS` ใน `code.gs`
- สถานะผู้ใช้บันทึกในชีต `user_status` (ยังไม่ตอบ / ตอบแล้ว) ใช้ตรวจไม่ให้ตอบซ้ำ
- ถ้าต้องการให้ผู้ใช้ตอบใหม่ ให้แก้ status ในชีต `user_status` กลับเป็น `ยังไม่ตอบ`

## การตอบ
ตารางแถวเดียวต่อข้อเหมือนต้นฉบับ: ที่ | รายการ | 👎 -1 | 👌 0 | 👍 +1 | ข้อเสนอแนะ

## หนังสือตอบรับการเป็นผู้เชี่ยวชาญ
- หลังกดส่ง ระบบสร้างหนังสือตอบรับ (Google Doc แบบอักษร Sarabun 16) จากชื่อ ตำแหน่ง หน่วยงาน ที่ผู้เชี่ยวชาญกรอก
- ผู้เชี่ยวชาญดาวน์โหลดได้ทั้ง PDF และ Word เพื่อลงนาม (login ซ้ำภายหลังก็ดาวน์โหลดได้อีก)
- ไฟล์เก็บใน Google Drive ของเจ้าของสคริปต์ โฟลเดอร์ `niti-mng หนังสือตอบรับผู้เชี่ยวชาญ` และมีลิงก์ในชีต `user_status`
- ไฟล์ตั้งค่าให้ "ทุกคนที่มีลิงก์ดูได้" เพื่อให้ผู้เชี่ยวชาญดาวน์โหลดได้
- แก้ข้อความหนังสือได้ที่ตัวแปร `LETTER` ใน `code.gs`

## ผลลัพธ์ใน Google Sheet
- ชีต `user_status` — สถานะการตอบ ชื่อ ตำแหน่ง หน่วยงาน และลิงก์หนังสือตอบรับของแต่ละผู้ใช้
- ชีต `responses` — คำตอบรายคน (IOC −1/0/+1 และข้อเสนอแนะรายข้อ)
- ชีต `ioc_summary` — ค่า IOC รายข้อ (ผ่านเกณฑ์เมื่อ ≥ 0.50) อัปเดตอัตโนมัติทุกครั้งที่มีผู้ส่ง หรือรัน `updateSummary` เอง
