# พฤติกรรมของ Canva MCP ที่ทดสอบจริง (พฤศจิกายน 2026)

ทดสอบบนดีไซน์ทดลอง หน้าขนาด 2000×2000 และ 3000×3000 ทุกข้อมีตัวเลขจาก response จริง

## ข้อความ (add_text / format_text)

| พฤติกรรม | ผลที่วัดได้ | ผลต่อการออกแบบ |
|---|---|---|
| ค่าเริ่มต้นหลัง add_text | 16px, lineHeight 1.4, ฟอนต์ `YACgEZ1cb1Q` (มีฟอนต์ไทยสำรอง), textAlign start | ต้อง format_text ทุกชิ้น |
| ความสูง 1 บรรทัด @16px | 18.8 ; 2 บรรทัด 40.8 ; 3 บรรทัด 62.8 | `init_h(n) = 18.8 + 22(n-1)` |
| ความสูงหลัง format | 30px: lh1.0 → 36/66/96, lh1.2 → 36/72/108 ; 40px → 48 | `h = fs·(1.2 + (n-1)·lh)` (คลาด < 1px) |
| ความกว้าง NATURAL (ไม่ใส่ width) | "P1.1" = 0.514em/ตัว ; ไทย ≈ 0.60em ต่อพยัญชนะ/สระที่กินที่ (สระบน-ล่าง/วรรณยุกต์ = 0) | ใช้ประมาณความยาว; ขยายตาม fs แบบเชิงเส้นพอดี (×2.5 เมื่อ 16→40) |
| ความกว้างรายตัว (วัด 10 ตัวติดกัน) | เ 0.295, ใ 0.289, ไ 0.304, โ 0.308, ะ 0.338, า/ำ 0.406, ร 0.488, ว 0.492, ก 0.600, พ 0.695, ญ/ณ 0.909, ฒ 0.903 em; ตัวเลข 0.556, จุด/ช่องว่าง 0.278 ; ไม่มี kerning (ผลรวมตรงกับคำจริง ±0.1px) | ตาราง `THAI_EM` ในสคริปต์ |

| ตัวหนา | ความกว้างเท่าตัวปกติ (ฟอนต์สำรองไทยไม่มีตัวหนาจริง) | ไม่ต้องเผื่อเพิ่ม |
| `left/top` ใน add_text | เป็นกรอบ **ก่อนหมุน** ; หมุนรอบจุดกึ่งกลางกล่อง | ตั้ง `left = cx - w/2`, `top = cy - h/2` ได้ตรงๆ |
| format_text บนข้อความ NATURAL ที่หมุนแล้ว | ความกว้างไม่ขยาย → ตัดทีละตัวอักษรเป็นแนวตั้ง ("P/1/./1") | **ห้าม** ใช้ NATURAL + rotation; ใส่ `width` (BLOCK) เสมอ |
| format_text บนข้อความ BLOCK ที่หมุนแล้ว | ความกว้างคงที่, ขอบบน (ในแกนของข้อความ) คงที่, กล่องโตลง | ศูนย์กลางเลื่อน `(h1-h0)/2` ตามเวกเตอร์ "ลง" ของข้อความ `(-sinθ, cosθ)` → ชดเชยล่วงหน้าตอน add (`add_text_op`) |
| ผลการชดเชย | 177/177 ข้อความ ศูนย์กลางคลาด < 3px จากเป้า, ไม่มีบรรทัดตกเกิน | ไม่ต้องมีรอบ position แก้ |

## การวางตำแหน่ง / ชั้น

| op | พฤติกรรม |
|---|---|
| `rotate_element` | หมุนรอบศูนย์กลาง, left/top (กรอบก่อนหมุน) คงเดิม |
| `position_element` | left/top = มุมบนซ้ายของ **กรอบ AABB หลังหมุน** (ไม่ใช่กรอบก่อนหมุน!) ตัวอย่าง 82×48 หมุน 90° สั่ง (300,300) ได้ left 282.85 top 317.15 |
| `layer_element front` | ย้ายไปบนสุด และย้ายไปท้ายรายการ `elements` ใน response |
| `group_elements` | ได้ element type `group`; locator ของลูกเปลี่ยนเป็น `PAGE-GROUP-CHILD` (id ลูกเปลี่ยนใหม่ด้วย) |
| ลำดับ ops ใน call เดียว | ทำตามลำดับ; ใช้ locator ที่สร้างใน call เดียวกันไม่ได้ (ยังไม่รู้ id) |

## รูปทรง (insert_shape)

- path รองรับ M L H V C S A Z (ไม่มี Q/T) ; donut sector = M-A-L-A-Z ทำงานถูกต้อง
- `width/height` = `view_box_*` → สเกล 1:1 ; ใช้กรอบพอดีชิ้น (tight bbox) ได้ — แต่ละเสี้ยวคลิกเลือกแยกได้
- `stroke_color` + `stroke_weight` ใส่ตอนสร้างได้ ; ไม่ใส่ `stroke_weight` = ไม่มีเส้นขอบ
- subpath หลายอันใน path เดียว (เช่น » สองตัว) ได้ 1 element
- เส้นขอบอยู่กึ่งกลางขอบ: เสี้ยวที่วาดทีหลังทับรอยต่อ → วาดวงนอกก่อนวงใน ให้ขอบขาวของวงในทับเรียบร้อย

## Response / transaction

- ทุก edit-design คืน **ทั้งหน้า** + ผลรายข้อ (~430 ตัวอักษรต่อ op) → เกิน 25k token เร็วมาก
- ส่วนเกินถูกตัด ("OUTPUT TRUNCATED") หรือถูกบันทึกเป็นไฟล์ (`Output too large … saved to`) — ไฟล์ก็ยังถูกตัดที่ 100,000 ตัวอักษร
- เอกสาร (elements) มาก่อนผลรายข้อ → element ช่วงต้นรายการอ่านได้เสมอ → ใช้ trick "ข้อความก่อน + layer front"
- `load_doc()` ในสคริปต์อ่าน element ทีละ object จากไฟล์ที่ถูกตัดกลางทางได้
- add_page response คืนเอกสารของหน้า `page_index` ที่ส่งไป ไม่ใช่หน้าใหม่ → ต้อง read-design หา page_id
- thumbnail URL (export-download.canva.com) อาจดาวน์โหลดไม่ได้จาก sandbox — ใช้ภาพที่ read-design แสดงแทน
- create-design ใส่เนื้อหา AI ในหน้า 1 เสมอ แม้ brief จะขอหน้าว่าง ; ลบหน้าผ่าน API ไม่ได้

## วงลูกศรรอบวงล้อ + animation

- ทำวงลูกศรทั้งวงเป็น **shape ชิ้นเดียว** (หลาย subpath ใน path เดียว) และตั้ง viewBox เป็นสี่เหลี่ยมจัตุรัสที่จุดกึ่งกลางตรงกับศูนย์วงล้อ (left = cx−R, top = cy−R, width = height = 2R) — Canva หมุน element รอบจุดกึ่งกลางกล่อง จึงหมุนรอบวงล้อพอดี
- ลูกศรตามเข็มนาฬิกา = มุมเพิ่มขึ้นในพิกัดจอ (y ชี้ลง); หัวลูกศรวางที่ปลายมุมมาก
- หน้า A3 ที่วงล้อรัศมี 527.8 เหลือขอบบน-ล่างแค่ ~34px → แถบลูกศร r 535–544, หัว 528.5–550.5 (ห่างขอบกระดาษ ~11px)
- API ใส่ animation ไม่ได้; Canva Help: animation ของ element **ตั้งให้วนต่อเนื่อง (loop) ไม่ได้** — ผู้ใช้ต้องเลือกชิ้นแล้วกด Animate เอง
