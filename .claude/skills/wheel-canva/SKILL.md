# wheel-canva — วงล้อหลายวงแหวนใน Canva (ทุกชิ้นแยกอิสระ)

สกิลนี้ใช้สคริปต์ `scripts/wheel.py` คำนวณเรขาคณิตและตำแหน่งตัวอักษรทั้งหมด แล้วยิงเป็น operations ของ
`mcp__Canva__edit-design` พฤติกรรมของ Canva ที่สกิลนี้พึ่งพา **ทดสอบกับ Canva จริงแล้วทั้งหมด** (ดู
`references/canva-behavior.md`) — อย่าเดาหรือเปลี่ยนลำดับขั้นตอนโดยไม่อ่านไฟล์นั้นก่อน

โครงสร้างวงล้อ (จากในออกนอก):

| ชั้น | เนื้อหา | ทิศตัวอักษร |
|---|---|---|
| วงกลมกลาง | ชื่อโมเดล (หลายบรรทัด ตัวหนา) | แนวนอน |
| วงแหวน A | รหัสด้าน (P, O, CM…) ตัวใหญ่ + ชื่อด้าน | แนวสัมผัส (ตั้งฉากรัศมี) ไม่กลับหัว / หรือโค้งตามวง |
| วงแหวน B | รหัสองค์ประกอบ (P1…) ตัวหนาที่ขอบนอก + ชื่อองค์ประกอบหลายบรรทัด | แนวรัศมี ไม่กลับหัว |
| วงแหวน C | รหัสข้อย่อย (P1.1…) | แนวรัศมี ไม่กลับหัว |
| วงนอกสุด | วงลูกศร + เครื่องหมาย » 4 จุด ชี้ตามเข็มนาฬิกา | — |

มุมของแต่ละด้าน/องค์ประกอบ = **สัดส่วนตามจำนวนข้อย่อย** (ทุกข้อย่อยกว้างเท่ากัน — แบบเดียวกับภาพต้นฉบับ)
เปลี่ยนเป็นเท่ากันทุกด้านได้ด้วย `"angle_mode": "equal"`

## 0. เตรียมข้อมูล (spec JSON)

ดูตัวอย่างเต็มที่ `examples/logistics_poccc.json` รูปแบบ:

```json
{
  "title": "บรรทัด 1\nบรรทัด 2\nบรรทัด 3",
  "options": {"size": 3000},
  "aspects": [
    {"code": "P", "name": "ด้านการวางแผน", "colors": ["#4A7FD0", "#8DB3E6", "#C9DAF2"],
     "components": [
       {"code": "P1", "name": "การวางแผนกลยุทธ์ด้านโลจิสติกส์และห่วงโซ่อุปทาน", "items": ["P1.1", "P1.2", "P1.3"]}
     ]}
  ]
}
```

- `colors` = [วงแหวน A (เข้ม), B (กลาง), C (อ่อน)] หรือใส่ `"color": "#xxxxxx"` ค่าเดียว แล้วสคริปต์ไล่โทนอ่อนให้
- รหัสองค์ประกอบซ้ำได้ (เช่น P6 แตกเป็น Man/Money/Machine/Material/Method = 5 องค์ประกอบที่ `code` เป็น "P6" ทั้งหมด)
- บังคับจุดตัดบรรทัดชื่อเองได้: ใส่ `\n` (ตัดตรงนั้นแน่นอน) หรือ `|` (จุดที่อนุญาตให้ตัด) — ถ้าไม่ใส่ สคริปต์ตัดคำไทยด้วย pythainlp และเลือกการตัดที่ทำให้บรรทัดยาวเท่าๆ กัน
- **ถ้าผู้ใช้ให้ภาพ/ไฟล์ต้นฉบับ** ให้ถอดข้อความจากต้นฉบับจริง (อ่านไฟล์ / ซูมภาพ) อย่าแต่งชื่อเอง ส่วนไหนอ่านไม่ออกให้ถามผู้ใช้
- ตัวเลือกที่ปรับได้ใน `options` (ค่าเริ่มต้นอยู่ใน `DEFAULTS` ของสคริปต์): `size`, `start_angle` (-90 = เริ่มบนสุด), `angle_mode`, รัศมีแต่ละวง `r_center r_a r_b r_c r_arrow` (สัดส่วนของ size), `arrow` (true/false), `curved_aspect`, ช่วงขนาดฟอนต์ `fs_item fs_name fs_aspect_code fs_aspect_name fs_title` เป็น [max, min], `center_color`, `sep_color`, `sep_w`

## 1. วางแผน + ตรวจในเครื่องก่อนแตะ Canva

```bash
pip install pythainlp   # ครั้งแรกเท่านั้น (ไม่มีก็ทำงานได้ แต่ตัดคำไทยหยาบกว่า)
python3 scripts/wheel.py plan spec.json --out WORK [--curved-aspect]
```

ได้ `WORK/plan.json` + `WORK/preview.png` (สี่เหลี่ยมแดง = กรอบข้อความที่ประมาณไว้) — **เปิด preview ดูก่อน**:
กรอบแดงต้องไม่ล้นเสี้ยวของตัวเอง ฟอนต์ที่เลือกพิมพ์ออกมาใน `fonts=...` ถ้าชื่อองค์ประกอบเล็กเกินไป (< ~24px ที่ size 3000)
แปลว่ามีเสี้ยวที่แคบมาก → เพิ่ม `size`, ขยาย `r_b`, หรือย่อชื่อ/บังคับตัดบรรทัด

## 2. เตรียมหน้าใน Canva

- ผู้ใช้มีดีไซน์อยู่แล้ว → ใช้ดีไซน์นั้น (หา design_id ด้วย `search-designs`)
- ไม่มี → `create-design` (brief สั้นๆ เช่น "blank white square canvas") แล้ว poll `get-create-design-async-job` จนได้ design id
  (AI จะใส่เนื้อหามาในหน้า 1 เสมอ — ไม่ต้องลบ ใช้หน้าใหม่แทน)
- `read-design` (`open_transaction: true`, fields `["page_metadata","thumbnails"]`) → `transaction_id`
- `edit-design` op `add_page` ขนาด `size×size` พื้นขาว → `read-design` ด้วย `transaction_id` + `filter.page_indices=[หน้าสุดท้าย]`, fields `["design_content"]` เพื่อเอา **page_id** (response ของ add_page ไม่บอก id หน้าใหม่)
- หน้า 1 ที่ AI สร้างลบผ่าน API ไม่ได้ (ไม่มี delete_page) → บอกผู้ใช้ให้ลบเองใน Canva หรือเก็บไว้

## 3. ลำดับการยิง (สำคัญมาก — ข้อความก่อน รูปทรงทีหลัง)

ทุก response ของ edit-design ส่ง **ทั้งหน้า** กลับมา และถูกตัดที่ ~25k token / 100k ตัวอักษร
element ใหม่อยู่ท้ายรายการ จึงหายไปก่อน — ถ้าวางรูปทรงก่อน จะไม่มีทางเห็น id ของข้อความที่เพิ่ง add
ลำดับต่อไปนี้ทำให้ id ที่ต้องใช้อยู่ต้นรายการเสมอ:

```bash
python3 scripts/wheel.py texts  WORK --page PAGE_ID --batch 90   # -> ops_text_add_1..N.json
python3 scripts/wheel.py shapes WORK --page PAGE_ID --batch 75   # -> ops_shapes_1..M.json
```

| call | operations | ได้อะไรกลับมา |
|---|---|---|
| T1 | `ops_text_add_1` | id ข้อความชุด 1 (อยู่ต้นรายการ) |
| T2 | `ops_text_add_2` + `ops_text_fmt_1` + `layer_element front` ของชุด 1 | ชุด 1 ถูกดันไปท้าย → id ชุด 2 อยู่ต้นรายการ |
| … | ทำซ้ำจนครบทุกชุด (ชุด k: add k + fmt k-1 + front ชุด 1..k-1) | |
| Tf | `ops_text_fmt_N` (ชุดสุดท้าย) | |
| S1..M | `ops_shapes_*` | รูปทรงไปอยู่บนข้อความ (ชั่วคราว) |
| L | `front` ของข้อความทั้งหมด (`python3 scripts/wheel.py front WORK`) | ข้อความกลับขึ้นบนรูปทรง |

การบันทึก id หลังแต่ละ call:
- ถ้า response ถูกบันทึกเป็นไฟล์ (`Output too large … saved to: FILE`) → `python3 scripts/wheel.py format WORK FILE` สร้าง fmt ให้อัตโนมัติ (จับคู่ด้วยข้อความ + ตำแหน่ง left/top ตอน add ซึ่ง Canva คงไว้เป๊ะ)
- ถ้า response แสดงในบทสนทนา (ไม่มีไฟล์) → คัด `id` ของ element ตามลำดับที่ปรากฏ แล้ว
  `python3 scripts/wheel.py locs WORK <batch_no> LBxxx LByyy ...` (จำนวน id ต้องเท่ากับจำนวนข้อความในชุด)
- รวมไฟล์ ops หลายไฟล์เป็น call เดียว: `python3 scripts/wheel.py merge WORK/callK.json f1.json f2.json ...`
  แล้ว `cat` ไฟล์นั้นมาใส่ใน `operations` (ต้องคัดลอกตรงทุกตัว)
- `front` เฉพาะบางชุด: `python3 scripts/wheel.py front WORK --batches 1,2`

ขนาดชุดที่ใช้ได้จริง: add_text ≤ ~90 ต่อ call, insert_shape ≤ ~75 ต่อ call, format/layer ≤ ~180 ต่อ call

## 4. ตรวจผลก่อนบันทึก

1. หลังจัดรูปแบบข้อความครบ (ก่อนวางรูปทรง) — ถ้ามีไฟล์ response:
   `python3 scripts/wheel.py check WORK FILE` → ต้องได้ `0 off` (ศูนย์กลางคลาดไม่เกิน tol และไม่มีบรรทัดตกเกิน)
   ถ้ามีรายการผิด ไฟล์ `ops_fix.json` มี resize/position แก้ให้แล้ว (position_element ใช้กรอบ AABB หลังหมุน — สคริปต์คำนวณให้)
2. `read-design` + `transaction_id` + `filter.fields=["thumbnails"]`, `thumbnail_pages=[หน้า]` → ดูภาพรวม (thumbnail 600px)
3. ให้ผู้ใช้ดู thumbnail และ **ขออนุญาตก่อน** `edit-design` `finalize: "commit"` (commit แล้วย้อนไม่ได้)
4. หลัง commit: `get-export-formats` → `export-design` PNG (`width` 3000) หรือ PDF เฉพาะหน้า (`format.pages`) แล้วส่งลิงก์ + `edit_url`

## 5. กติกาเลย์เอาต์ที่ใช้ (ถ้าจะปรับมือ)

- **upright(a) = ((a + 90) mod 180) − 90** — ใช้กับทุกข้อความ: แนวรัศมี `rot = upright(มุมกึ่งกลางเสี้ยว)`,
  แนวสัมผัส `rot = upright(มุม + 90)` → ครึ่งขวาอ่านจากในออกนอก ครึ่งซ้ายอ่านจากนอกเข้าใน ไม่มีตัวกลับหัว (เหมือนต้นฉบับ)
- ข้อความแนวรัศมี: กล่องกว้าง (BLOCK width) = ความยาวตามรัศมี, ความสูง = จำนวนบรรทัด × ระยะบรรทัด ต้องไม่เกินคอร์ดของเสี้ยวที่รัศมีด้านใน
- ชื่อองค์ประกอบใช้ฟอนต์ **ขนาดเดียวกันทั้งวง** (= ขนาดที่พอดีกับเสี้ยวที่แคบที่สุด) รหัสองค์ประกอบ = 1.18× ตัวหนา ที่ขอบนอกวงแหวน B
- ป้ายด้าน: รหัส (ตัวใหญ่) อยู่ฝั่ง "หัวตัวอักษร" ชื่อด้านอยู่ฝั่ง "เท้า" → ครึ่งบนรหัสอยู่นอก ครึ่งล่างรหัสอยู่ใน; สคริปต์เช็คมุมกล่องไม่ให้ล้นวงแหวน (กล่องตรงบนวงโค้งจะยื่นที่ปลาย)
- ข้อความโค้ง (`--curved-aspect`): แยก 1 element ต่อ 1 กลุ่มอักษร (พยัญชนะ+สระบน/ล่าง+วรรณยุกต์ ห้ามแยกสระลอย) ระยะห่างตามความกว้างจริงของแต่ละตัว
  ครึ่งบนเดินตามเข็ม `rot = มุม+90`, ครึ่งล่างเดินทวนเข็ม `rot = มุม−90` ให้อ่านซ้ายไปขวา; รวมกลุ่มได้ด้วย `group_elements` (locator ของลูกจะเปลี่ยนเป็น `PAGE-GROUP-CHILD`)
- เสี้ยวทุกชิ้นใช้ **กรอบพอดีชิ้น (tight bbox)** ไม่ใช่กรอบเต็มวง → คลิกเลือกใน Canva ได้ถูกชิ้น ย้าย/เปลี่ยนสีทีละเสี้ยวได้
- ลำดับชั้น: วงลูกศร → วงแหวน C → B → A → วงกลมกลาง → ข้อความทั้งหมดบนสุด

## 6. ข้อจำกัดที่ต้องบอกผู้ใช้

- Canva MCP **เปลี่ยนฟอนต์ไม่ได้** (format_text ไม่มี font family) ข้อความใช้ฟอนต์ค่าเริ่มต้น ถ้าต้องการ TH Sarabun New ฯลฯ ให้ผู้ใช้เลือกข้อความทั้งหมดใน Canva แล้วเปลี่ยนเอง — ฟอนต์ไทยส่วนใหญ่แคบกว่าค่าเริ่มต้น จึงไม่ล้นกรอบ
- Canva ไม่มี "ข้อความโค้ง" ผ่าน API — โหมดโค้งจึงเป็นตัวอักษรแยกชิ้น (แก้คำต้องลบแล้วสร้างใหม่) ค่าเริ่มต้นจึงใช้ข้อความตรงแนวสัมผัส ซึ่งแก้ไขได้ทั้งคำ
- ลบหน้าผ่าน API ไม่ได้ / thumbnail ใน transaction ได้แค่ ~600px — ตรวจละเอียดหลัง export

## 7. การแก้ไขภายหลัง

ทุกชิ้นแยกกันอยู่แล้ว: แก้คำ → `find_and_replace_text`/`replace_text` (ถ้าข้อความยาวขึ้นมากให้ `resize_element` กว้างขึ้น),
เปลี่ยนสีเสี้ยว → `recolor_element`, เส้นแบ่ง → `update_stroke_properties`, ย้าย → `position_element` (ระวัง: ใช้กรอบ AABB หลังหมุน)
หาตำแหน่ง/locator ของชิ้นที่ต้องการจาก `plan.json` (มี `tag` เช่น `name:P3:2`, `item:P3.1`, `acode:P` และ `locator`) — เก็บโฟลเดอร์ WORK ไว้
