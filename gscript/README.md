# แบบสอบถามเดลฟาย รอบที่ 2 — Google Apps Script Web App

โปรเจกต์นี้เป็นเว็บแอปที่รันบน Google Apps Script สำหรับแบบสอบถามเดลฟาย
รอบที่ 2 (เวอร์ชันตามเอกสาร PDF ล่าสุด รวม 127 ข้อคำถาม) และบันทึกคำตอบทุกฉบับ
ลง Google Sheet โดยอัตโนมัติ พร้อมชีตอ้างอิงรายการคำถามทั้งหมดไว้ให้ผู้วิจัยดูคู่กัน
ก่อนเริ่มตอบ ผู้ตอบต้อง "เข้าสู่ระบบ" ด้วยรหัสผู้เชี่ยวชาญ (`res01`–`res21`,
รวม 21 ท่าน) — ระบบจะตรวจสอบว่ารหัสนั้นเคยส่งคำตอบมาแล้วหรือยัง และบล็อกไม่ให้
ตอบซ้ำ

## โครงสร้างไฟล์

- `Questions.gs` — **แหล่งข้อมูลคำถามหลักเพียงที่เดียว** (`SECTIONS`) ครอบคลุมทั้ง
  5 ด้าน (P/O/CM/Co/CT) ใช้ทั้งฝั่งเว็บฟอร์มและฝั่งชีตอ้างอิง แก้คำถามที่ไฟล์นี้
  ไฟล์เดียวพอ
- `Code.gs` — server-side script:
  - `doGet()` เสิร์ฟหน้าเว็บ (ฝัง `SECTIONS` เป็น JSON เข้าไปใน `Index.html`
    ตอน render) และสร้างชีต `คำถามอ้างอิง` อัตโนมัติถ้ายังไม่มี
  - `checkRespondentStatus(username)` ตรวจสอบรูปแบบรหัส (`res01`–`res21`)
    และเช็คว่าเคยมีคำตอบของรหัสนี้ในชีต `Responses` แล้วหรือยัง เรียกจาก
    หน้า Login ก่อนแสดงแบบสอบถาม
  - `submitSurvey()` รับข้อมูลจากฟอร์มแล้วบันทึกเป็นแถวใหม่ในชีตชื่อ `Responses`
    (ตรวจซ้ำอีกครั้งภายใต้ `LockService` ว่ารหัสนี้ยังไม่เคยส่ง เพื่อกันกรณี
    เปิดสองแท็บส่งพร้อมกัน)
  - `refreshQuestionReference()` ฟังก์ชันที่รันเองได้จาก Apps Script editor
    (เมนู Run) เพื่อล้างและเขียนชีต `คำถามอ้างอิง` ใหม่ทั้งหมดหลังแก้ไข
    `Questions.gs`
- `Index.html` — เทมเพลตหน้าฟอร์ม (โครงหน้า/สไตล์/สคริปต์ฝั่งไคลเอนต์) โดยดึง
  รายการคำถามจาก `Questions.gs` ผ่านตัวแปร `sectionsJson` ที่ `doGet()` ฝังให้
  ไม่ได้ฮาร์ดโค้ดคำถามไว้ในไฟล์นี้แล้ว
- `appsscript.json` — manifest กำหนดค่าเว็บแอป (deploy แบบให้ทุกคนเข้าถึงได้
  โดยไม่ต้องล็อกอิน)

## วิธีติดตั้ง (ผ่านเว็บ script.google.com)

1. สร้าง Google Sheet ใหม่ (ไฟล์นี้จะเป็นที่เก็บคำตอบ) ตั้งชื่อตามต้องการ เช่น
   "ผลตอบแบบสอบถามเดลฟาย รอบที่ 2"
2. ในชีตนั้น ไปที่เมนู **ส่วนขยาย (Extensions) → Apps Script**
3. ในโปรเจกต์ Apps Script ที่เปิดขึ้นมา ลบไฟล์ `Code.gs` เริ่มต้นแล้วสร้างไฟล์
   ใหม่ตามชื่อในโฟลเดอร์นี้:
   - สร้างไฟล์สคริปต์ชื่อ `Code` แล้ววางเนื้อหาไฟล์ `Code.gs`
   - สร้างไฟล์สคริปต์อีกไฟล์ชื่อ `Questions` แล้ววางเนื้อหาไฟล์ `Questions.gs`
   - สร้างไฟล์ HTML ชื่อ `Index` แล้ววางเนื้อหาไฟล์ `Index.html`
   - เปิดไฟล์ `appsscript.json` (ต้องเปิดใช้งาน "Show appsscript.json" ผ่าน
     ไอคอนฟันเฟือง Project Settings → Show "appsscript.json" manifest file
     in editor) แล้วแทนที่ด้วยเนื้อหาไฟล์ `appsscript.json` ในโฟลเดอร์นี้
4. บันทึกโปรเจกต์ทั้งหมด (Ctrl/Cmd+S)
5. กด **Deploy → New deployment**
   - เลือกประเภท **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone** (หรือ Anyone with Google account ถ้าต้องการ
     จำกัดผู้ตอบ)
   - กด Deploy แล้วอนุญาตสิทธิ์การเข้าถึง (authorize) ตามที่ระบบขอ
6. คัดลอกลิงก์ **Web app URL** ที่ได้ แล้วส่งให้ผู้เชี่ยวชาญที่จะตอบแบบสอบถาม

พอเปิดเว็บแอปครั้งแรก ระบบจะสร้างชีต **`คำถามอ้างอิง`** ให้อัตโนมัติ ในนั้นมี
รหัสข้อ, หมวด/ด้าน, ระดับ (หลัก/ย่อย) และข้อความคำถามครบทั้ง 127 ข้อ ไว้ให้ผู้วิจัย
เปิดดูคู่กับคอลัมน์ในชีต `Responses` ได้ทันที (ไม่ต้องเปิดอ่านโค้ด)

เมื่อมีผู้ตอบแบบสอบถามและกด "ส่งแบบสอบถาม" ระบบจะสร้างชีตชื่อ `Responses`
ในสเปรดชีตเดียวกัน พร้อมสร้างหัวตารางอัตโนมัติในการบันทึกครั้งแรก
(คอลัมน์ `timestamp`, `username` + ข้อมูลส่วนที่ 1 + ทุกรหัสข้อคำถาม
P.../O.../CM.../Co.../CT... + `part3_suggestion`) และเพิ่มแถวใหม่ทุกครั้งที่มีการส่งฟอร์ม

### หน้า Login / กันตอบซ้ำ

ก่อนเห็นแบบสอบถาม ผู้ตอบต้องกรอกรหัสผู้เชี่ยวชาญในรูปแบบ `res01`–`res21`
(พิมพ์ตัวพิมพ์ใหญ่/เล็กก็ได้ ระบบจะแปลงเป็นตัวพิมพ์เล็กให้อัตโนมัติ) กด
"เข้าสู่ระบบ" แล้วระบบจะ:

- ถ้ารหัสนั้น**ยังไม่เคยส่งคำตอบ** → แสดงแบบสอบถามให้ตอบตามปกติ (มีป้ายชื่อ
  รหัสผู้ตอบกำกับไว้ด้านบนตลอด)
- ถ้ารหัสนั้น**เคยส่งคำตอบไปแล้ว** → แสดงข้อความแจ้งว่าเคยตอบไปแล้วเมื่อไร
  และไม่แสดงแบบสอบถามให้ตอบซ้ำ

ไม่มีรหัสผ่านแยกต่างหาก (ใช้ username เพียงอย่างเดียวตามที่ตกลงไว้) จึงเหมาะ
กับกลุ่มปิดที่รู้รหัสกันอยู่แล้วเท่านั้น หากต้องการความปลอดภัยเพิ่มในอนาคต
สามารถเพิ่ม PIN ต่อรหัสได้ที่ `RESPONDENT_PATTERN`/`normalizeUsername_`
ใน `Code.gs`

## วิธีติดตั้งด้วย clasp (ทางเลือกสำหรับสาย dev)

หากต้องการพัฒนา/deploy จากเครื่องด้วย [clasp](https://github.com/google/clasp):

```bash
npm install -g @google/clasp
clasp login
cd gscript
clasp create --type webapp --title "Delphi Round 2 Survey" --rootDir .
clasp push
clasp deploy
```

`clasp create --type webapp` จะสร้างสเปรดชีตแบบ standalone ให้ใหม่
หากต้องการผูกกับ Google Sheet ที่มีอยู่แล้ว ให้ใช้ `clasp clone <scriptId>`
ของสคริปต์ที่ผูกกับสเปรดชีตนั้นแทน

## หมายเหตุ

- ทุกครั้งที่แก้จำนวน/รหัสข้อคำถามใน `Questions.gs` (ตัวแปร `SECTIONS`) ให้:
  1. ลบชีต `Responses` เดิมทิ้งก่อนเปิดรับคำตอบชุดใหม่ ไม่เช่นนั้นหัวตารางเดิม
     จะไม่ตรงกับข้อคำถามชุดใหม่ (สคริปต์จะเติมค่าตามหัวตารางที่มีอยู่แล้วในชีต
     เสมอ ไม่สร้างคอลัมน์ใหม่ให้เอง)
  2. รันฟังก์ชัน `refreshQuestionReference` จาก Apps Script editor (เลือกฟังก์ชัน
     นี้ที่แถบด้านบนแล้วกด Run) เพื่ออัปเดตชีต `คำถามอ้างอิง` ให้ตรงกับคำถามชุดใหม่
- ใช้ `LockService` เพื่อป้องกันข้อมูลชนกันเมื่อมีผู้ตอบพร้อมกันหลายคน
